# ai-space-supply-tracker
Tool that uses AI and a camera to track spacecraft supplies and alert crews when items are running low.

# Project Idea: AI Space Supply Tracker
This tool uses a camera and AI to help NASA crews keep track of supplies aboard a spacecraft or space station. The camera scans storage areas, and the AI identifies items and estimates how many are left. The system can flag low supplies so crews can plan ahead and avoid running out of essentials.

# Technologies and Tools
- Python
- A camera, such as a webcam
- AI image recognition to identify supply items
- OpenCV to capture and process camera images
- A simple inventory list to save item names and counts

# How to Run and Use the Project
1. Connect a camera to the computer running the tool.
2. Install Python and the project’s required libraries.
3. Start the program.
4. Point the camera at a storage area and take a picture or scan the shelves.
5. Review the AI’s detected items and quantities.
6. Correct any mistakes, then save the inventory.
7. Check the low-supply alerts and update the inventory after items are used or restocked.
The AI’s counts should be checked by a crew member, especially when items are blocked from view or stored in unusual packaging.
