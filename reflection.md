# Project Reflection

I learned how to use GitHub and create files, commits, branches, and pull requests, as well as merge them. I learned how to manage and organize a project on GitHub by creating boards and publishing issues.

I would improve the implementation of the AI vision system to track different aspects of the spacecraft, not only the storage and supplies but also other things, like the expiry date of these items.
